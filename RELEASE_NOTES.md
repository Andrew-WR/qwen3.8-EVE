# EVE beta 0.2.2

Download `eve-beta-0.2.2.zip` from this release. Its SHA-256 is:

```text
b4835d775ab5f2cb934ebf5936171871d62fedbcfc1af23d0ea5978757e9e3d2
```

Fill out the [beta form](https://tally.so/r/Dq2q75). Its completion
page gives you a beta code, image repository, and unlock code. Follow
`START_HERE.md` inside the ZIP; there is no separate handoff download.

This release supports an exact Hugging Face Qwen3.8-27B checkpoint ID and
revision. The default remains the original INT4 model. The new image and
installer have passed local configuration, signature, and non-GPU checks; full
Qwen 27B and multi-GPU validation on alternate checkpoints remains in progress.
